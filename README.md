智能环境监测与控制小程序
基于微信小程序 + OneNET云平台的温湿度监测与远程控制系统

📖 项目简介
通过微信小程序实时显示环境温湿度，并远程控制报警器和LED灯。硬件设备通过OneNET云平台与小程序通信。

🏗️ 系统架构
text

     |                |
  数据显示         数据存储
  远程控制         指令下发
  🚀 快速开始
